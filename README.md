# CharPixel

Turn images into shareable ASCII art in the browser.

## Features

- Upload or drop an image
- Tune character detail with a live ASCII preview
- Copy raw ASCII text
- Download the output as `.txt` or a share-ready PNG
- Fully local processing: no account, database, backend, or image upload

## Run locally

```bash
npm install
npm run dev
```
